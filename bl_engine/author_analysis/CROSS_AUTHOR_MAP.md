# Cross-source mechanism map — integrated

The synthesis is **dimension-owned, condition-aware, and non-averaged**.

| Dimension | Primary owner | Conditional contributors | Forbidden takeover |
|---|---|---|---|
| Focal attention / base prose realization | Attention-realization model | pressure/body/relationship state | humor/story engines cannot rewrite surface by authority |
| Character-local inference / humor | Character-frame model | relationship/common-ground state | cannot dictate causality or paragraph layout |
| Reader hypotheses / evidence / reveal mode | Reader-evidence architecture | character knowledge, recurrence, causality | cannot dictate lexical register or narrator voice |
| Plan / option / strategic ecology | Agency architecture | reader model, relationship permissions | cannot grant characters knowledge they do not have |
| Character cognition | Current actor state | all specialist procedures may propose | no source model may replace current grounded evidence |
| Relationship permissions | Canonical relationship state | dialogue/action/agency procedures | no declaration may replace evidence-backed change |
| Prose style manifold | Synthetic author realization identity | scene condition / pressure | stylometry is verifier boundary, not writer quota |
| Creative search | Runtime controller | all source-derived mechanisms may evaluate candidates | cannot transform user/canon hard anchors |

Conflict order:

1. user/canon authority;
2. runtime truth and provenance;
3. actor-reachable evidence;
4. local causality/affordance;
5. relationship permissions and current interaction frame;
6. dimension ownership;
7. source/style preference.

Never average incompatible traits merely to preserve all sources.
