# LIFE CARD — 실화 카드 (블로그·에세이용, 한 번 채우고 계속 쓴다)

블로그 글의 디테일은 여기서만 가져온다. 비워 둔 칸은 지어내지 않는다. 짧게, 말하듯 적는다. 이 카드는 블로그에 올리지 않는다.

| 칸 | 적는 것 | 예(지어낸 예시. 실제 내용으로 바꾼다) |
|---|---|---|
| 하루 동선 | 출퇴근 수단, 자주 지나가는 곳 | 버스 두 번 갈아탐, 환승 정류장 앞 붕어빵 트럭 |
| 자주 나오는 사람 | 2~3명, 블로그용 별명 | 회사 옆자리 '부장님 말고 차장님', 대학 동기 '조별과제' |
| 요즘 꽂힌 것 | 음식·노래·물건·영상 | 같은 다섯 곡짜리 플레이리스트 |
| 진짜 싫은 것 | 사소할수록 좋다 | 엘리베이터 닫힘 버튼 안 누르는 사람 |
| 이상한 습관 | 남들은 안 하는데 나는 하는 것 | 계절 바뀌면 플레이리스트 이름만 바꿈 |
| 말버릇 | 실제로 자주 쓰는 말 2~3개 | 암튼, ~하긴 함, 미친 |
| 동네 특징 | 우리 동네에만 있는 것 | 은행나무 길이 유난히 김 |
| 최근 있었던 일 | 이번 주 일 3개, 아무 일이나 | 혼자 간 결혼식, 비밀번호 찾기, 우산 잃어버림 |
| 블로그를 시작한 진짜 이유 | 한두 줄, 멋 부리지 않고 | |

쓰는 법: 매일 글감을 받으면 이 카드에서 **글감과 상관없어 보이는 칸 하나**를 골라 붙인다. 글감과 딱 맞는 칸만 고르면 글이 다시 설계처럼 읽힌다.
