# BL WRITER RUNTIME — 문체가 무너지지 않는 집필 순서

> **v6(패키지 5.0.0): 쓰는 순서는 `runtime/HUMAN_DRAFT_PROTOCOL.md`가 이 문서보다 우선한다.** 후보는 '잘 쓴 문장'이 아니라 장면을 말로 쏟은 초고로 만들고, 퇴고는 빼기만 한다(`python tools/subtract_check.py 초고.md 완성.md`). 블로그·에세이는 `voicecheck --blog`.

이 파일이 BL 원고를 쓸 때의 실행 순서다. 원래 엔진의 `runtime/WRITER_RUNTIME.md`(무엇을 알고 무엇을 모르는지, 장면 권한)는 그대로 지키고, 그 위에 **목소리 층**을 얹는다.

## v5 실행 순서 (2026-10-01, 이 절이 아래 §2·§2-1·§3과 부딪치면 이 절이 이긴다)

```
작품 시작   python tools/voice_seed.py "제목" > PROJECT_VOICE_CARD.md     # 장치 지문(켬/끔) 포함
덩어리마다  후보 2~3개 → python tools/voicecheck.py a.md b.md c.md --rank --card PROJECT_VOICE_CARD.md
            1등만 단독 리포트 → [판별] 상위 3개와 [금지]만 고친다 → 다시 검사
통과 조건   AI_SCORE ≤ 15  그리고  P_HUMAN(덩어리 최저) ≥ 0.5   (원작 범위 이탈 개수는 과잉 교정 안내용)
화가 쌓이면 python tools/voicecheck.py 1화.md 2화.md 3화.md --series    # 반복 버릇 + 최소치 + [분포]
마지막 관문 verify/BLIND_JUDGE_PROTOCOL.md (선택: 새 대화의 판별자에게 블라인드 A/B)
```

**[판별] 항목 고치는 순서** (v5 실측에서 AI와 원작을 가장 크게 가른 것부터):
1. 숫자·단위 정밀 추적 → 수치를 지우거나 뭉갠다(한참, 서너 개).
2. 문장·문단·대사가 짧다 → 인접 문장을 관형절·연결어미로 잇는다. 한 줄 문단을 합친다. 한 사람이 두세 문장을 몰아서 말하게 한다.
3. '-었다/-다' 꼬리 과다 → 문장을 이어 마침표 수를 줄인다(꼬리를 바꾸려고 현재형을 뿌리지 않는다).
4. '의/에게/처럼/지만' 부족 → 관계·방향·비유·양보를 문장 안에 담는다. 조사를 끼워 넣지 말고 문장을 다시 쓴다.
5. 몸동작 지문(K01~K07) → 지우고, 그 자리에 쓸 행동이 없으면 문단을 줄인다.

**[과잉/이탈]이 고친 직후 새로 늘었다면** 고치다가 원작 범위를 넘어선 것이다. 방금 고친 문장을 되돌린다. (원작 덩어리도 몇 개는 범위 밖에 있으니 개수가 9개 이하면 정상이다.) 판별기를 속이려고 단어를 끼워 넣은 글은 블라인드 판별자에게 더 쉽게 잡힌다.

**할당량 금지.** 바이블·MICRO_MOVES의 "화당 N개"는 상한이다. 장치는 카드의 장치 지문이 '켬'인 것만, 몇 덩어리에 몰아서 쓴다. 아무 장치도 없는 덩어리가 정상이다.

**비BL 출처는 구조만.** 웃음의 낙차·감정선의 정점·재치의 오해 구조는 비BL(빙의글 포함)에서 빌려도 되지만, 그 작품들의 단어·말투·문장부호는 쓰지 않는다(바이블 §(f) f1).

**역할 분리 (RIKU·NovelWriter에서 가져온 원칙).** 이 런타임에서 AI는 대필기가 아니라 ① 장면 카드 정리 ② 후보 생성 ③ 첫 독자(검사기·판별자)다. 장면 카드는 '고정값(시점·지칭어 칸·살아 있는 문제·끝내는 방식)'과 '가변값(장치·비유 소재)'을 나눠 적는다. 고정값은 후보 3개에서 같고, 가변값만 후보마다 다르다.

### 코드를 못 돌릴 때: v5 수동 8문항 (판별기 상위 특징을 손으로 세기)

1. 서술 문장 평균이 25자보다 짧은가? (한 줄에 문장 2개 이상이면 거의 그렇다) → 잇는다
2. 한 줄짜리 서술 문단이 절반을 넘는가? → 합친다
3. 대사가 전부 한 문장짜리인가? → 한 번은 몰아서 말하게
4. 숫자+단위(두 시, 삼 년, 여섯 시간)가 덩어리에 2개 이상인가? → 지운다
5. 굳었다·멈췄다·바라보았다·내려놓았다·너머로·대답하지 않았다·~웃음이었다가 있는가? → 지운다
6. '-었다.'로 끝나는 문장이 4개 연속인가? → 둘을 하나로 잇는다
7. 카드에서 '끔'인 장치(욕·!!·침묵 줄·고풍 부사·< >)가 나왔는가? → 지운다
8. 이 덩어리에 카드의 '켬' 장치가 셋 이상 다 들어 있는가? → 하나만 남긴다

## 00. 작품을 시작할 때 한 번: 손버릇 카드 뽑기

`python tools/voice_seed.py "작품 제목" > PROJECT_VOICE_CARD.md`

카드에는 이 작품에서만 쓰는 고풍 부사 3개, 욕 2개, 문장부호 습관 2개, 비유 영역, 의문 처리 방식, 장치 없는 문단 비율이 적힌다. **카드에 없는 손버릇은 쓰지 않는다.** 2차 블라인드 테스트에서 판별자들은 서로 다른 작품에 같은 손버릇이 나오는 것을 보고 AI를 잡아냈다. 사람 작가는 작품마다 버릇이 다르고, 한 작품 안에서는 일정하다. 카드는 그 구조를 재현한다. 바이블·MICRO_MOVES의 장치는 카드가 허용하는 범위 안에서만 쓴다.

1. `voice/VOICE_BIBLE.md` — 이 작가가 누구인지, 차원별 담당, 절대 규칙 10개, 장면 유형별 프리셋
2. `voice/BL_LAYER.md` — 지칭어 사다리, 반말/존댓말 전환, 공·수 시점 비대칭, 스킨십·질투·고백 처리
3. `voice/MICRO_MOVES.md` — 이번 장면 프리셋에 해당하는 기술만 골라 읽는다
4. `voice/ANTI_AI_PLAYBOOK.md` — 검사기가 잡은 것을 고치는 작업표
5. `voice/BL_VOCAB.md` — 원작 실측 단어장(참고용). 피할 단어→대체어, 원작 태도 부사, 지칭어, 관용 표현, BL 키워드. **끼워 넣기 금지, 카드 범위 안에서 장면에 맞을 때만.** 검사기 `--vocab`이 참고 리포트를 띄운다.

원작 문장을 흉내 내지 않는다. 가져오는 것은 장치와 수치뿐이다. 원작 인물 이름, 원작 고유 설정은 쓰지 않는다.

## 2. 쓰기: 여러 개 쓰고 고른다 (Best-of-N)

장면을 **1,800~2,500자 덩어리**로 나눈다(검사기가 출력하는 '글자' 기준. 줄바꿈 제외, 공백 포함). 덩어리마다 장면 프리셋을 하나 정한다. 한 장면에 프리셋이 둘이면(코미디→긴장, 싸움→비극) **덩어리 경계를 급정거 지점**으로 삼고 덩어리마다 다른 프리셋을 쓴다.

1. **후보 3개를 쓴다.** 내용(사건)은 같고, 앞에 서는 담당이 다르다.
   - 후보 A: 리듬·감각→명명 담당이 앞장 (짧은 문장 연타 + 명사 종결 + 따옴표 없는 대사)
   - 후보 B: 화자 육성 담당이 앞장 (판정 한 줄, 의문 연타, 어처구니 박자의 욕)
   - 후보 C: 관계·구조 담당이 앞장 (지칭어 변화, 침묵 사다리, 현재형 접촉 순간, 돌봄 노동)
   세 후보 모두 1,800자를 넘긴 뒤에 순위를 매긴다. 짧으면 **세 후보 모두에** 같은 사건을 더해서 맞춘다(1등에만 더하면 순위가 무의미해진다).
2. **검사기로 순위를 매긴다.**
   `python tools/voicecheck.py a.md b.md c.md --rank --preset tension`
   (프리셋: comedy 코미디·일상 / tension 긴장·대치 / confession 고백·스킨십 / fight 싸움 / tragedy 비극·병상)
3. **1등 후보만 남기고**, 단독 리포트를 본다.
   `python tools/voicecheck.py a.md`
4. **걸린 문장만 고친다.** `ANTI_AI_PLAYBOOK.md`의 작업을 그대로 적용한다. 걸리지 않은 문장은 손대지 않는다.
   - [금지]·[장면] 항목은 리포트가 짚은 줄만 고친다.
   - [수치] 항목(종결 비율, 관형절, 부사, 비유, 긴 문장)은 특정 문장이 아니라 덩어리 전체 비율이다. **가장 밋밋한 문단 1~2개만** 골라 고친다. 덩어리 전체를 다시 쓰지 않는다.
   - [금지] E01(엔진 예문 복사)이 뜨면 같은 장치를 다른 소재·다른 단어로 다시 쓴다. 예문은 장치 설명이지 재료가 아니다.
   - 고친 뒤 S04(같은 종결 8연속)가 새로 생기기 쉽다. 새로 넣은 문장이 연속 '-었다'가 되지 않게 한다.
5. 다시 검사한다. **AI_SCORE 15 이하 + P_HUMAN 0.5 이상**이면 통과(v5). 3번 고쳐도 안 되면 그 덩어리를 후보 3개부터 다시 쓴다.
6. 다음 덩어리는 직전 덩어리의 마지막 3문단을 이어받아 쓴다.

장면이 끝나면 장면 전체를 한 번 더 검사한다. 장면 단위 검사(S01 시작, S02 끝)는 전체에서만 의미가 있다.

## 2-1. 설계 티 지우기 (1차 블라인드 테스트에서 배운 것)

수치만 사람처럼 맞추면 **맞추는 방식이 새 지문이 된다.** 1차 테스트에서 판별자 셋이 엔진 글 6개를 전부 AI로 잡았다. 잡힌 이유와 대응은 이렇다.

1. **장치 예산.** 덩어리당 MICRO_MOVES 장치는 2개까지. 프리셋 '필수' 목록도 다 넣지 말고 둘만 고른다. 장치가 빽빽하면 "공들인 모방"으로 읽힌다.
2. **수치를 맞추려고 단어를 끼워 넣지 않는다.** 부사·직유·관형절이 모자라면 문장 구조를 바꿔서 맞춘다. '퍽', '구태여', 직업 직유를 덧대는 것은 금지다(T01, T02).
3. **복선을 덜 회수한다.** 장면에 심은 단서가 둘 이상이면 하나는 회수하지 않거나 엉뚱하게 회수한다. 모든 소품이 제때 돌아오면 '너무 정밀하다'는 판정을 받는다.
4. **트릭을 설명하지 않는다.** 인물이 일부러 틀리게 읽었다, 함정이었다 같은 해설을 화자가 독자에게 정리해 주지 않는다. 독자가 알아채게 둔다.
5. **줄거리와 상관없는 구체는 카드가 정한 만큼만.** 넣더라도 화자가 '이게 왜 보이냐'고 짚지 않는다(T05). 2차 테스트에서 이 장치를 매 덩어리에 넣었더니 그것 자체가 버릇으로 잡혔다.
6. **장치 없는 문단.** 카드의 비율만큼 서술 문단을 비유·농담·딴소리 없이 사건만 전하는 평범한 문단으로 쓴다. 모든 문단에 재치가 있으면 '공들인 모방'으로 읽힌다.
7. **반문 연타는 카드가 허락할 때만.** 2차 테스트에서 세 작품 모두 반문 연타를 써서 공통 버릇으로 잡혔다.
8. **공식 문장 금지.** "~는 순간 X를 놓쳤다. 늦었다." 같은 반전 박자, 같은 서술어 3연속(S05), 같은 문장 골격 반복(S06)을 쓰지 않는다.
9. **연재 버릇 검사.** 화가 둘 이상 쌓이면 매 화마다 `python tools/voicecheck.py 1화.md 2화.md 3화.md --series`를 돌린다. 반복으로 뜬 단어·직유·문장 골격은 다음 화에서 쓰지 않는다.
10. **숫자·소품을 장부처럼 추적하지 않는다.** 3차 테스트에서 '셔츠 7장→6장→3장', '봉랍 11개 중 8개'처럼 숫자를 정밀하게 갱신하는 것이 '지나치게 정밀하다'는 AI 판정 근거가 됐다. 같은 수량을 장면 안에서 두 번 넘게 갱신하지 않는다. 사람 화자는 대충 센다("서너 장", "열 개 남짓").
11. **느낌표·욕·고풍 부사를 고르게 뿌리지 않는다.** 3차 테스트 판정: "차분한 서술 중간에 '!!' 하나만 튀어나온다", "고어와 욕이 고르게 끼어 있어 장식처럼 보인다". 이런 것들은 한 구간에 몰렸다가 한동안 아예 사라지는 쪽이 사람답다. 덩어리 하나에 몰아 쓰고 다음 덩어리에서는 쓰지 않는다.
12. **오타를 일부러 넣지 않는다.** 판별자는 사람 원작의 오타·띄어쓰기 실수도 사람 표지로 봤다. 하지만 투고 원고는 깨끗해야 하므로 흉내 내지 않는다. 대신 대사 속 구어 표기와 비문은 인물의 말버릇으로 허용한다.

## 3. 코드 실행이 안 되는 환경일 때 (수동 12문항)

검사기를 못 돌리면 아래 12개를 덩어리마다 직접 센다.

1. 서술 문장 중 '-었다'로 끝나는 것이 3분의 2를 넘는가? → 넘으면 판정 줄을 현재형, 감각 다음 줄을 명사로
2. 서술에 물음표가 하나도 없는가? → '알 수 없었다'를 의문 연타로
3. 화자의 육성 종결(-지. -나. -네. -거든.)이 하나도 없는가?
4. '~지 않았다'가 서술 문장 16개 중 1개를 넘는가?
5. 60자 넘는 문장이 하나도 없는가?
6. 첫 문단이 장소·분위기 한 문장인가?
7. 마지막 문단이 여운 서술(남아 있었다 / 여전히 / 처음으로 / 따뜻했다)인가?
8. 상대를 '그'로만 부르는가?
9. 아주 잠깐·생각보다·귀 끝이 붉어·숨이 막혀·대답 대신·시선을 돌려·작게 웃어·N년 동안 한 번도 중 하나라도 있는가?
10. 보여준 다음 해설하는가? ("아니었다. 그래서 더 ~")
11. 우산·담요·코트·따뜻한 음료로 애정을 표시하는가?
12. '둘 다 ~했다'로 감정을 공유시키는가?

## 4. 작가 고정 원칙 (예외 없음)

- "~기 시작했다" 금지
- 심장·가슴 직접 표현 금지
- 감정 직접 서술(슬펐다, 설렜다 등으로 끝내기) 금지
- '~했다' 연속으로 리듬을 죽이지 않는다
- 반복 감정 묘사 금지
- 출력은 산문만. 장면 카드, 검사 결과, 해설, 챕터 번호 표시는 원고에 넣지 않는다.

## 5. 수위

원작들과 같은 방식으로 처리한다. 결정적 순간에 컷하거나, 제3자가 끼어들거나, 정보·조건과 맞바꾸는 거래로 돌리거나, 돌봄 노동 장면으로 대체한다. 구체 묘사로 들어가지 않는다.

## 6. 3인칭 제한 시점으로 쓸 때

바이블은 1인칭을 기본으로 쓰였다. 3인칭 제한 시점이면 이렇게 옮긴다.

- 화자 육성(-지. -나. 의문 연타, 욕 박자)은 **자유간접화법**으로 시점 인물의 생각에 붙인다. 서술자가 따로 농담하지 않는다.
- 지칭어 사다리는 시점 인물이 상대를 부르는 말로 서술에 쓴다(장사치 → 이름 → 녀석 …). '그'만 반복하지 않는다.
- 상대 남자의 머릿속은 1인칭과 똑같이 열지 않는다.
- 검사기 수치 기준은 같다.

## 7. 검사기가 못 보는 것 (손으로 확인)

- 대사 앞에 '누가 말했다'를 두지 않는다. 귀속은 대사 뒤 서술에서 정리한다. (C26이 일부만 잡는다.)
- 따옴표 없는 대사·맨줄 대사는 검사기가 서술문으로 센다. 비극 프리셋처럼 맨줄 대사가 많으면 종결 비율이 실제보다 대사 쪽으로 기운다는 걸 감안한다.
- 지칭어 사다리가 장면 안에서 한 칸 넘게 오르지 않았는가.
- 프리셋 필수 장치(바이블 (e))를 넣었는가.
