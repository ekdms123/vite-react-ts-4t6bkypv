# v0.2 Executable Kernel Contract

The runtime follows nine release-blocking invariants:

1. Truth never comes from creativity.
2. Capability never grants authority.
3. The writer never receives knowledge it cannot legitimately realize.
4. Model default has zero automatic authorial authority.
5. Material durable transformations require reason, authority, and evidence/provenance.
6. PASS requires proof that every required verifier actually executed.
7. Failed or assurance-not-met prose cannot mutate durable state.
8. Generated prose cannot teach itself into durable author identity without explicit source/user/compiler authority.
9. No implementation claim exists without executable-contract evidence.

Official flow:

`SceneContract -> grounded/partial models -> creative routing -> positive ProjectionCompiler -> RealizationPacket -> prose -> mandatory verification receipts -> PASS/FAIL/ASSURANCE_NOT_MET -> typed StateDelta -> semantic-hash/version commit`.

Structural verification and literary superiority are separate gates. The package may prove executable contracts without claiming blind literary or commercial superiority.
