# MICRO MOVES — GJ 마이크로 무브 58종

> 9개 분석에서 겹치는 것을 합쳐 하나로 정리했다. 모든 예문은 새로 지었다(BL. 나=윤재: 코인세탁소 사장 / 석하진: 재개발 용역 대표 / 오 실장 / 조카 미소). 출처: 여름·세디·철수·마왕·홍염(BL), 염라·차금·개복·러버(비BL, 서술·유머 기계만).
> 규칙: 무브는 VOICE_BIBLE (b)의 **차원 주인** 아래에서만 쓴다. 빈도 한도는 '1만 자당'이나 '장면당'이다. 한도를 넘기면 그 무브가 문체의 틱이 된다.

## Ⅰ. 리듬·명명·냉소 (주인: 여름 / 장문만 마왕)

**MM01 지각→명사 판정** — 리듬·명명 / 여름
- 템플릿: `[감각 사건]. [정체 명사](이)었다.` 또는 `[정체 명사].`
- 예문: 건조기 3번에서 쇠 갈리는 소리가 났다. 동전이었다. 누가 바지 주머니를 안 털었다.
- 언제: 새 사물이나 인물이 감각으로 먼저 들어올 때. 수수께끼를 내고 바로 푸는 반 박자 지연.
- 남용: 1만 자당 15 이하. 연속 2회 금지.

**MM02 즉시 반박** — 냉소 / 여름
- 템플릿: `(무따옴표 허세 대사). 물론 뻥이었다. 실은 [초라한 진실].`
- 예문: 이거 이태리에서 맞춘 거야. 물론 뻥이었다. 실은 시장 수선집 아줌마가 단을 줄여 준 바지였다.
- 언제: 인물이 허세를 부리면 서술자가 독자에게만 까 보인다.
- 남용: 장면당 1회.

**MM03 장부식 환산** — 냉소 / 여름
- 템플릿: `[금액·대가]는 [생활 단위]의 N배였고 [더 하찮은 단위]의 M배였다.`
- 예문: 녀석이 받으러 온 이자는 세탁기 한 번 돌리는 값의 육백 배였고, 내가 하루 동안 개는 수건 값의 스무 배였다.
- 언제: 돈, 폭력, 계급 격차를 도덕 논평 없이 보여 줄 때.
- 남용: 작품당 3회. 숫자는 개그용으로만 정밀하게 쓴다(C08 주의).

**MM04 모순 쌍 판정** — 냉소 / 여름
- 템플릿: `[X]한데 [반대 Y]했다.` / `X라기엔 Y했고 Z라기엔 W했다.`
- 예문: 깡패라기엔 구두가 너무 깨끗했고, 회사원이라기엔 손등에 흉이 너무 많았다.
- 언제: 상대를 볼 때마다 위험과 귀여움을 한 문장에 겹친다. 끌림을 이름 붙이지 않고 보여 주는 기본 장치다.
- 남용: 1만 자당 3.

**MM05 단락 내 무인용 핑퐁** — 무따옴표 대사 / 여름
- 템플릿: `대사. [동작 한 줄]. 대사. 대사.` (한 단락, 따옴표 없음)
- 예문: 어디 가. 석하진이 넥타이를 풀다 말았다. 어디 가냐고. 동전 바꾸러요. 지폐 교환기 저기 있는데.
- 언제: 리듬을 끊지 않고 짧은 주고받음을 서술에 녹일 때.
- 남용: 장면당 2단락. 4턴을 넘기면 따옴표로 뺀다.

**MM06 삼킨 말의 뒤늦은 판정** — 무따옴표 대사 / 여름
- 템플릿: `(무따옴표 대사 1~2문장). [그 말을 하지 않았다 / 속으로만 했다는 서술].`
- 예문: 그 손 치워요, 내 가게에서. 목구멍까지 올라온 말은 거기서 굳었다. 나는 손 대신 바구니를 치웠다.
- 언제: 한 말과 삼킨 말이 같은 형식이어서 독자가 반 박자 늦게 알아야 할 때.
- 남용: 장면당 1회.

**MM07 '이번엔' 점층 사슬** — 리듬 / 여름
- 템플릿: 같은 상대가 같은 행동을 반복할 때 `이번엔 [한 단계 높은 것]이었다.`
- 예문: 녀석이 또 문을 밀고 들어왔다. 이번엔 빈손이 아니었다. 김밥 두 줄. 다음 날 또 왔다. 이번엔 오 실장까지 딸려 왔다.
- 언제: 반복 방문, 반복 도발이 관계를 한 칸씩 올릴 때.
- 남용: 한 장 안에서 사슬 하나, 3고리까지.

**MM08 잠든 얼굴 공식** — 끌림 / 여름
- 템플릿: `[상대가 먼저 잠듦] → [호흡 변화] → [나이보다 어려 보임] → [기분이 이상했다/판정 회피].`
- 예문: 녀석은 접이식 의자에서 고개를 뒤로 꺾고 잠들었다. 들숨이 일정해졌다. 서른넷은 무슨, 졸업 앨범 속 얼굴이었다. 기분이 영 별로였다.
- 언제: 끌림이 커졌는데 명명하면 안 되는 시점. 손을 대도 눈꺼풀이나 머리카락 한 올 정도로 줄인다.
- 남용: 작품당 3~4회. 매번 장소를 바꾼다.

**MM09 무인용 소원 단독 행** — 무따옴표 / 여름
- 템플릿: 섹션 마지막 줄에 `[상대에게 하는 존댓말이나 반말 소원 한 줄]`. 따옴표 없음, 태그 없음.
- 예문: 내일은 나보다 늦게 나가요.
- 언제: 감정 정점에서 섹션을 닫을 때. '기도했다'는 쓰지 않는다.
- 남용: 작품당 4회.

**MM10 욕설 지칭 + 안 어울리는 미덕** — 냉소·지칭 / 여름
- 템플릿: `그 [욕설 명사] 주제에 [반듯한 미덕].`
- 예문: 그 사채 양아치 주제에 동전은 꼭 앞면이 위로 오게 쌓아 놓고 갔다.
- 언제: 사다리 0~2칸. 경멸과 관찰이 같이 있어야 한다.
- 남용: 1만 자당 2.

**MM11 압력 장문** — 장문 / 마왕
- 템플릿: `[관형절]+[관형절]+명사가 -고/-면서 [동작]하는 순간 [충돌 동작]했다.` (60자 이상, 문단당 1개)
- 예문: 철거 예정 딱지가 덕지덕지 붙은 유리문 너머에서 장부를 겨드랑이에 낀 채 담배를 비벼 끄던 녀석이 고개를 드는 순간 나는 들고 있던 세제 통을 놓쳤다.
- 언제: 긴장이 쌓인 문단의 한가운데. 바로 뒤에 2~6자 단문을 붙인다.
- 남용: 문단당 1개. 쉼표는 0~1개(C21).

## Ⅱ. 화자의 육성 (주인: 염라 — 기계만)

**MM12 대사 직후 판정 한 줄** — 육성 / 염라
- 템플릿: `“[상대의 상식 밖 진술].”` / `[현재형 판정 '-다'.]`
- 예문: “이 건물, 내가 샀어. 오늘부로 네 건물주.” / 미친놈이다. 확실하다.
- 언제: 상대가 거창하거나 터무니없는 말을 하면 다음 줄에서 묘사 없이 판정한다.
- 남용: 1만 자당 8. 같은 판정어를 반복하지 않는다.

**MM13 3박 펀치** — 육성·욕 박자 / 염라
- 템플릿: `[사소한 피해 보고 -었다]. [욕 한 마디]. [과장된 사소한 결심].`
- 예문: 녀석이 내 드럼에 지 와이셔츠를 몰래 섞어 돌렸다. 씨. 오늘부로 3번 세탁기는 출입 금지 구역이다, 이 망할.
- 언제: 화자가 손해 보는 일상 사건마다.
- 남용: 장면당 1회.

**MM14 의문 연타 + 대안 하나** — 육성 / 염라(대안 단독 행은 마왕)
- 템플릿: `[자문]? [자문]? [자문]?` → 단독 문단 `아니면, [엉뚱하거나 무서운 대안]?`
- 예문: 왜 하필 우리 가게야? 동전 교환기 때문에? 내가 지난주에 침 뱉은 거 봤나? // 아니면, 처음부터 나를 보러 오는 거야?
- 언제: '~인지 알 수 없었다'가 나올 자리 전부.
- 남용: 1만 자당 3세트.

**MM15 겉말/속말 이중 트랙** — 육성 / 염라
- 템플릿: `“[공손한 대답].”` 다음 행 `[같은 내용의 반말 + 욕 버전]`.
- 예문: “아, 네. 천천히 보고 가세요.” / 천천히는 무슨, 빨리 꺼져라 제발.
- 언제: 위계가 있거나 손님 앞이라 겉으로 굽혀야 할 때.
- 남용: 장면당 2회.

**MM16 욕 마침표** — 욕 박자 / 염라
- 템플릿: `[평서문], [욕].` 문장 끝 욕이 마침표 노릇을 한다.
- 예문: 오늘따라 동전이 하나도 안 걸리네, 염병.
- 언제: 어처구니없음, 체념, 감탄. 분노 설명 문장과는 같이 쓰지 않는다.
- 남용: 1만 자당 3~10. 비극 프리셋에서는 0.

**MM17 장기 세입자** — 육성(설렘 처리) / 염라
- 템플릿: 설렘을 몸 내부 기관이나 세입자 취급하며 욕한다(가슴·심장 단어 금지).
- 예문: 갈비뼈 안쪽 세입자가 또 바닥을 굴렀다. 방 빼, 보증금 없어.
- 언제: C23·C24 자리에 들어간다.
- 남용: 작품당 3회. 같은 비유 재사용 금지.

**MM18 프로필 카드 반전** — 인물 등장 / 염라
- 템플릿: `- [정보] / - [정보] / - [정보] / - [사소하거나 저속한 반전]` (첫 소동이 가라앉은 직후)
- 예문: - 오 실장. 마흔 언저리. / - 석하진 밑에서만 십 년. / - 무표정, 무대답. / - 세탁물 개는 거 나보다 잘함. 짜증 남.
- 언제: 이름 단독 문단 등장(ANTI X06) 대신.
- 남용: 주요 조연 1인당 1회, 작품당 4회.

## Ⅲ. 관계 엔진 (주인: 마왕/홍염)

**MM19 침묵 사다리** — 침묵 / 마왕
- 템플릿: `“[한 절].”` / `“…….”` / `“[한 절].”` / `“…….”` … / `“[침묵하던 쪽의 한 줄 반격].”`
- 예문: “이 동네 다음 달에 비워.” / “…….” / “보상금 두 배로 쳐 줄게.” / “…….” / “네 가게는 세 배.” / “…….” / “왜 말이 없어.” / “세 배면 계산기 두들겨 봐야지.”
- 언제: 고백, 협박, 설득, 브리핑. 말하지 않는 쪽의 존재감이 필요할 때. 끝을 '질문→침묵→셀프 결론'(차금식)으로 비틀어도 된다.
- 남용: 장면당 1개, 사다리당 침묵 3~7줄.

**MM20 현재형 정지 컷** — 시제 / 마왕
- 템플릿: `[과거 액션 2~4문장]. [상대의 접촉·시선 현재형 1문장]. [화자 반응 과거형].`
- 예문: 선반이 무너졌고 세제 통이 줄줄이 굴렀다. 나는 바닥에 엉덩방아를 찧었다. 커다란 손이 내 뒷덜미를 쥐고 들어 올린다. 엉덩이가 젖어 있었다.
- 언제: 지점①. 일상 장면에서는 상대의 하찮은 동작에 쓴다(러버 카메라 흡수).
- 남용: 문단당 현재형 4문장 이하.

**MM21 2인칭 현재형 신체 중계** — 시제·지칭 / 홍염
- 템플릿: 서술에서 상대를 `너`로 부르고 동작 3~4개를 현재형으로 → 화자 반응 1개를 과거형으로.
- 예문: 네가 소매를 걷는다. 젖은 셔츠를 비틀어 짠다. 물이 네 손목을 타고 팔꿈치로 흘러내린다. 나는 걸레를 들고 서 있기만 했다.
- 언제: 사다리 3칸 이상. 고백·스킨십 프리셋.
- 남용: 장면당 1회.

**MM22 지칭 교체 노출** — 지칭 사다리 / 마왕
- 템플릿: 한 문단 안에서 `[이전 칸 지칭]` → `[다음 칸 지칭]`. 전환 자체가 보이게.
- 예문: 녀석은 또 대답을 안 했다. 지겹게 그랬다. 그런데 오늘은 대답을 안 하는 네 입꼬리가 씰룩거렸다.
- 언제: 관계가 한 칸 오르는 사건 직후.
- 남용: 장면당 1칸.

**MM23 정보-접촉 내기** — 거래 / 마왕
- 템플릿: `“[미스터리] 하나 알려 주지.”` / `“조건.”` / `“[명사 한 단어].”` / `“미쳤냐?!”` → 서술로 약점 진단.
- 예문: “이 동네 누가 팔았는지 알려 줄까.” / “조건.” / “발.” / “뭐?!” / “발 좀 씻겨 봐. 오늘 하루 종일 걸었거든.” // 이 인간은 내가 못 거절하는 것만 골라서 판다.
- 언제: 정보 비대칭이 있는 관계의 전반부.
- 남용: 장당 1회. 대가는 매번 바꾼다.

**MM24 작전-스킨십 줄다리기** — 거래 / 홍염
- 템플릿: 화자가 정보를 묻는다 → 상대가 접촉으로 회피한다 → 화자가 경쟁자나 적의 이름을 꺼낸다 → 상대가 멈추고 삐친 연기 존대 → 화자가 다시 추궁한다.
- 예문: “구청 쪽은 누가 쥐고 있어?” 녀석의 엄지가 내 귓불을 집는다. “3동 김 사장 생각할 거야, 지금.” 손이 멈췄다. “와, 너무하시네. 나 지금 상처받으셨어요.”
- 언제: 연인 확정 후 정보를 계속 감추는 관계.
- 남용: 장당 1회.

**MM25 '거다' 역추론 계단** — 시제·추론 / 홍염
- 템플릿: `[관찰 사실]. 녀석은 [의도]한 거다. [근거] 때문이다. [평가 명사문].`
- 예문: 철거 딱지가 우리 가게에만 없었다. 녀석이 일부러 빼 놓은 거다. 이웃들이 나를 의심하게 만들어야 했기 때문이다. 더러운 수작이다.
- 언제: 상대가 먼저 일을 벌이고 화자가 뒤늦게 해독할 때.
- 남용: 장면당 1세트(긴장·대치 프리셋의 필수 1세트 포함). 1만 자당 3세트 이하.

**MM26 단언 계단** — 시제(지점③) / 마왕
- 템플릿: 한 줄 문단 3~5개를 현재형으로, 낮은 단정에서 높은 단정 순으로.
- 예문: 이건 빚 때문이 아니다. // 안다. // 너는 여기 앉아 있으려고 온다. // 매일.
- 언제: 화자의 확신이 굳는 순간. 장 끝 근처.
- 남용: 장당 1개.

**MM27 회상 대사 끼우기** — 표기·회상 / 마왕(기호는 철수)
- 템플릿: 현재 대사 한 줄 → `「과거 대사」` 3~5줄(과거 침묵 「…….」 포함) → `아, 그거.` → 상기 내용 한 줄.
- 예문: “약속은 지켰다.” // 「살아서 오면?」 / 「…….」 / 「살아서 오면 그때 말해 줄게.」 // 아, 그거. 가게 셔터 내리던 그날 밤.
- 언제: 초반에 던진 대사를 회수할 때(정리된 회상 문단 ANTI X09 대신).
- 남용: 장당 1회.

**MM28 해독 엔딩 훅** — 장 끝 / 홍염
- 템플릿: 사건 공표 대사 한 줄 → `그리고 이제야 네 [행동]의 뜻을 알겠다.` → 2인칭 선언 한 줄.
- 변형(정체 삼행): `나는 X다. / Y해서 얻은 이름이다. / 그래서 계속 Z해야 한다.`
- 예문: “3동 김 사장 사무실, 압수수색 들어갔대.” // 그리고 이제야 네가 아침에 내 가게 동전을 죄다 바꿔 간 뜻을 알겠다. // 판 깔았네. 내 차례야.
- 언제: 장 끝 6유형 중 해독형과 선언형.
- 남용: 같은 유형은 3장 연속 금지.

**MM29 말투 전환 탐지** — 존대 사건 / 홍염
- 템플릿: 상대의 연기조 존대 한 줄 → `저 말투가 나오는 걸 보니 [제3자]가 온다.` → 실제로 등장한다.
- 예문: “아이고 사장님, 오늘도 손님이 많으시네요.” / 저 느끼한 존댓말이 나오는 걸 보면 계단에 누가 있다. 아니나 다를까 구둣발 소리가 셋.
- 언제: 공적 자리에서 연기하는 상대를 화자만 읽을 때.
- 남용: 작품당 3회.

**MM30 선택지 협박이 고백** — 고백 비틀기 / 마왕
- 템플릿: `“첫째, [A].”` / `“둘째, [B].”` → 화자의 서술 한 줄이 뜻을 뒤집는다.
- 예문: “첫째, 보상금 받고 이 동네 떠.” / “둘째, 남아서 내 장부 정리해.” // 지금 이 인간은 혼자 두지 말라고 빌고 있다.
- 언제: 정보 우위인 쪽의 고백 대체.
- 남용: 작품당 2회.

## Ⅳ. 표기·문단·돌봄·급전 (주인: 철수)

**MM31 하이픈 흡수 대사** — 표기 / 철수
- 템플릿: `[내 행동]. [상대의 짧은 말].- [내 반응].`
- 예문: 젖은 운동화를 건조기에 넣었다. 그거 넣으면 고무 녹는다.- 알아, 안다고. 나는 운동화를 도로 꺼냈다.
- 언제: 짧은 대답을 문단 밖으로 빼지 않고 리듬을 유지할 때.
- 남용: 1만 자당 10. 문단당 2.

**MM32 같은 대사 재인용** — 표기 / 철수
- 템플릿: `“[대사].”` → 다음 문단 `[대사].- 라고. [쪼갠 수식 단문 2~3].`
- 예문: “가 봐.” // 가 봐.- 라고. 장부를 덮지도 않고. 숫자 세던 손가락도 안 멈추고.
- 언제: 화자가 한 마디를 곱씹는 멜로 구간.
- 남용: 장당 1회.

**MM33 판결 + 오해 상상** — 문단 닫기 / 철수
- 템플릿: `[장면 2~3문장]. [명사]+이다. [남이 보면 오해할 거라는 반말 혼잣말].`
- 예문: 다 큰 남자 둘이 이불 커버 한 장을 양쪽에서 잡아당겼다. 줄다리기 결승이다. 손님 들어오면 경찰 부르겠네.
- 언제: 코미디 문단을 닫을 때. 카메라를 멈추고 자막을 다는 효과.
- 남용: 1만 자당 6.

**MM34 자기 철회** — 문단 닫기 / 철수
- 템플릿: `[무심코 긍정]. 취소, 방금 거 취소. [원래 입장 재선언].`
- 예문: 저 나이엔 원래 다 그렇게 붙어 다니지. 취소, 방금 거 취소. 다 큰 놈들이 왜 컵라면 하나를 나눠 먹어.
- 언제: 화자가 진심을 들킬 뻔했을 때. 반드시 원위치나 더 큰 착각 쪽으로 철회한다(C06 금지 방향).
- 남용: 1만 자당 2.

**MM35 명사 종결 클로즈업** — 문단 닫기 / 철수
- 템플릿: `[구체 동작 + 사소한 디테일]하는 [현재 사다리 칸의 지칭어].`
- 예문: 귤껍질을 끊지 않고 한 줄로 벗겨 놓고 혼자 흐뭇해하는 석하진.
- 언제: 화자의 애정 섞인 시선을 명명하지 않고 깔 때.
- 남용: 1만 자당 4.

**MM36 도치 애정 폭발** — 육성(멜로 직전) / 철수
- 템플릿: `[관찰 2문장]. [형용사]가지고 진짜.`
- 예문: 잠결에 내 앞치마 끈을 쥐고 놓지를 않는다. 코까지 이불을 끌어 올리고. 기가 막혀가지고 진짜.
- 언제: 감정이 차서 문장 완성을 포기하는 순간.
- 남용: 작품당 4회.

**MM37 마침표 절단** — 비극 리듬 / 철수·세디
- 템플릿: `[주어]가. [서술어]. [부사구]. [부사구].` 또는 `[수식어]. [핵심 서술].`
- 예문: 녀석이. 웃고 있었다. 링거 바늘을 꽂은 채로. 멀쩡한 척도 안 하고.
- 언제: 비극·병상. 숨이 끊기는 효과(M05 대체).
- 남용: 장면당 2회.

**MM38 정적 줄 세우기** — 침묵(철수 변형) / 철수
- 템플릿: 굳은 인물 수만큼 `“…….”` 연속 → 제3자의 4~6자 직구.
- 예문: “…….” / “…….” / “삼촌, 둘이 뽀뽀해?”
- 언제: 오해받기 딱 좋은 순간에 제3자가 들어왔을 때(MM39와 짝).
- 남용: 장면당 1회.

**MM39 오해 유발 정지화면** — 끊기 / 철수
- 템플릿: 가장 오해받기 좋은 자세에서 끊는다 → 의성어 컷 `벌컥-` → 실재 인물이 들어와 남아서 판을 엎는다.
- 예문: 녀석이 내 바지 밑단을 걷어 올리고 무릎에 연고를 문지르던 참이었다. 벌컥- 문을 연 미소가 책가방을 떨어뜨렸다. 삼촌!!! 이모한테 사진 찍어 보낸다!!!
- 언제: 스킨십 직전 차단(ANTI X05 익명 소음 대체).
- 남용: 3장에 1회.

**MM40 돌봄 노동 = 고백** — 애정=노동 / 철수
- 템플릿: `[신체 부위]를 [돌봄 동작]한다. [축소 비유]. 나는. [사랑한다는 말을 동작에 맡기는 문장].`
- 예문: 발톱을 하나씩 깎는다. 강낭콩만 한 새끼발톱까지. 나는. 대답을 기다리는 사람처럼 아주 오래 그 발을 붙들고 있었다.
- 언제: 멜로·병상. 고백 대신.
- 남용: 장면당 1회. 같은 부위를 다시 돌아오게 해서 시간 경과를 보여 준다.

**MM41 결과 먼저, 경위는 역행** — 오프닝 / 철수
- 템플릿: 장 첫 줄을 사건의 결과 한 줄로 → `일은 점심때 시작됐다.` 류의 평이한 역행.
- 예문: 결국 녀석을 세탁기에 처넣었다. 다리만. // 일은 점심때, 오 실장이 빈 장바구니를 들고 오면서 시작됐다.
- 언제: 무대 설정 오프닝(ANTI X01) 대신.
- 남용: 3장에 1회.

**MM42 급정거** — 톤 급전 / 철수
- 템플릿: 코미디 문단(느낌표·의성어) → 빈 줄 → 멜로 문단 첫 문장은 신체 사실 하나(축소어).
- 예문: 이 인간이 진짜!!! 나는 녀석의 등을 세 대 갈겼다. // 등뼈가 손바닥에 하나하나 다 걸렸다.
- 언제: 웃기던 장면의 바닥에 상실의 징후가 있을 때. 전환은 한 번, 되돌리지 않는다.
- 남용: 장당 1회.

## Ⅴ. 비유·꺾쇠·문자·말 번역 (주인: 세디)

**MM44 일반론 → 적용** — 비유·냉소 / 세디

**MM45 꺾쇠 되새김** — 꺾쇠 / 세디

**MM46 꺾쇠 압축 대화** — 꺾쇠 / 세디

**MM47 문자 원문 재현** — 문자 / 세디
- 템플릿: `[오타·은어 살린 원문]` → 해석 한 줄.

**MM48 거짓말 → 사실 단독 단락** — 냉소 / 세디
- 템플릿: `“[핑계].”` → 빈 줄 → `[핑계를 무너뜨리는 사실 한 문장].`
- 예문: “나 빨래 같은 거 안 해 봤어.” // 녀석의 와이셔츠 소매는 늘 손빨래한 것처럼 목둘레까지 반듯했다.
- 언제: 인물의 허세나 숨김을 서술자가 건조하게 깰 때.

**MM49 말하지 않은 노력** — 끌림 / 세디
- 템플릿: `[상대를 위한 수고]했다는 말은 하지 않았다.`
- 예문: 녀석이 좋아하는 섬유유연제를 찾으려고 마트 세 군데를 돌았다는 말은 하지 않았다.

**MM50 무게 조절 발화** — 고백 비틀기 / 세디

**MM51 거친 말 번역 주석** — 끌림 / 세디
- 템플릿: `그러니까 이 인간 사전에서 '[다정한 말]'은 '[거친 말]'로 등재돼 있었다.`
