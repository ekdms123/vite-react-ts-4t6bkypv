# Optional Cognition Router

No scene must be classified into a fixed universal taxonomy before writing.

Temporary artifacts may be requested when they can change a live decision:

- mystery → belief/evidence map
- flashback → present-relevance memory map
- reveal → reveal accounting
- relationship pivot → accumulated relationship evidence
- deception → claim/knowledge map

Every artifact is disposable cognition, not canonical story state. Everyday scenes may route nothing.
