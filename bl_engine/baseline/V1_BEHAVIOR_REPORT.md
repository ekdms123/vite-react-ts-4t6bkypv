# V1 baseline notes

The supplied V1 contains a rich author model and useful sparse-prior principles, but its runtime requires a fixed seven-axis classification including a closure target. Its packaged tests primarily validate package structure and fixture legality rather than executing a live author router against expected scene behavior.

V2 treats V1 as an immutable conceptual baseline and adds deterministic regression gates around the observed failure classes rather than claiming those gates were already behaviorally enforced by V1.
