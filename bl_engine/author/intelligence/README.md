# Author Intelligence Library

Selectable writer intelligence is stored as small source-clean capability cards. Selection is evidence-driven and sparse. Card ownership never widens canon, POV knowledge, source-dimension authority, or surface-contract permissions. Writer context receives only compiled card payloads, never manifests or audit vocabulary.

Class A cards are selectable. Class B audits live in `VERIFIER_AUDITS.md` and are verifier-only. Class C hard invariants remain in the kernel and are never optional.
